# EstimateStepper

Оценка карточки шагами: `Takt.EstimateStepper` из `web/src/shared/ui/EstimateStepper.tsx`.

- «Без оценки» — отдельное состояние (`null`), а не ноль: ноль значит «оценили и почти ничего».
- Единица одна на доску: очки, часы или дни; подпись склоняется по числу.
- Кнопки ± — цели нажатия 24×24, число можно набрать руками.

Свойства: `value` (число или `null`), `unit` (`points`/`hours`/`days`), `onChange`, `id`.
