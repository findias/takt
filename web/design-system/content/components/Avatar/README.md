# Avatar

Кружок с первой буквой имени, тон выбирается по имени. `Takt.Avatar` и `Takt.AvatarMore` из `web/src/shared/ui/Avatar.tsx`.

- Восемь тонов через 45° (`avatar-0` … `avatar-7`): задача аватара — различать людей, а не называть их.
- Буква белая в обеих темах. Размер задаётся числом (по умолчанию 20px), буква — 0.55 от него.
- Узел скрыт от диктора (`aria-hidden`), имя целиком — в `title` и в подписи рядом.
- В стопке `avatars` лишних людей заменяет `avatar-more` («+3»).

Свойства: `name`, `size`.
