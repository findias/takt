# ConfirmDialog

Вопрос перед необратимым действием: `Takt.ConfirmDialog` из `web/src/shared/ui/Dialog.tsx`.

- Спрашивает только необратимое; обратимое (архив) выполняется сразу и предлагает вернуть.
- Текст называет, что исчезнет и что станет с зависимым («шесть карточек перейдут…»).
- Кнопка подтверждения повторяет действие словами («Удалить колонку»), а не «ОК».
- Нативный `<dialog>` с `showModal`: ловушка фокуса и Escape от браузера. Диалог закрывается до тоста, который доложит о результате.

Свойства: `open`, `title`, `children`, `confirmLabel`, `danger`, `busy`, `confirmDisabled`, `onConfirm`, `onCancel`.
