# Mark

Знак Takt — метроном, сложенный из карточек: `Takt.Mark` из `web/src/shared/ui/Mark.tsx`. Корпус — доска из карточек в три колонки и четыре ряда, маятник задаёт такт, орбита уносит готовую карточку дальше по потоку.

- Три ступени по размеру, компонент выбирает сам по `size`: от 64 px — с чёрточками заголовков на карточках; от 32 — без чёрточек; меньше 32 — метроном из трёх рядов с маятником, без колонок, орбиты и летящей карточки (у 16 px они сливаются в шум).
- Цвета свои, не токены темы: корпус — градиент слева направо `#5ade8e` → `#16ad82` | `#1a93cf` → `#1f68cc` (зелёная половина встречает синюю по центру), поток (маятник, орбита, карточка) — `#1bb3d6`. Щели и вырезы — маска, сквозь них виден фон, поэтому знак верен на обеих темах. Не перекрашивать, не растягивать, не отражать, без тени и блеска.
- Где стоит: шапка — 24 px, перед названием организации; вход — 56 px; первая загрузка — 40 px с качающимся маятником (`swing`: ±33°, период 1.4 s; при «меньше движения» — проявление). Вкладка браузера — `/favicon.svg`, малая ступень; README и документация — `web/public/takt-mark.svg`, полная.
- Охранное поле — половина высоты знака со всех сторон. Слово «Takt» рядом — системный шрифт, 650; знак по высоте — кегль × 1.4.

Свойства: `size` (пиксели), `swing` (качать маятник).
