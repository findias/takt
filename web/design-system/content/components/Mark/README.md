# Mark

Знак Takt — метроном, сплошной: `Takt.Mark` из `web/src/shared/ui/Mark.tsx`. Система знака — холст «Takt — логотип», вариант 05.2.

- Две версии по размеру: полная — от 32 px (с основанием, маятник 3.5), малая — меньше 32 (без основания, маятник 4.5, груз крупнее: вырез не залипает в пиксельной сетке). Компонент выбирает сам по `size`.
- Цвет — `--accent` темы; вырез — маска, сквозь него виден фон. Не красить в `warn`, не растягивать, не отражать, без тени и блеска.
- Где стоит: шапка — малый, 24 px, перед названием организации; вход — полный, 56 px; первая загрузка — 40 px с качающимся маятником (`swing`: ±15°, период 1.4 s; при «меньше движения» — проявление). Вкладка браузера — `/favicon.svg`, малый знак.
- Охранное поле — половина высоты знака со всех сторон. Слово «Takt» рядом — системный шрифт, 650; знак по высоте — кегль × 1.4.

Свойства: `size` (пиксели), `swing` (качать маятник).
