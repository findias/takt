# Menu

Меню действий под кнопкой: `Takt.Menu` из `web/src/shared/ui/Menu.tsx`.

- Список живёт в верхнем слое браузера (`popover`), поэтому колонка с прокруткой его не обрезает.
- Опасный пункт (`danger`) стоит последним и окрашен `warn`; необратимое носит многоточие — дальше будет вопрос.
- Пункт с `checked` — переключатель (`menuitemcheckbox`): исполнители, метки.
- Закрывается по Escape и возвращает фокус на кнопку.
- На карточке меню «…» закрывает WCAG 2.5.7: «Переместить» доступно одним нажатием.

Свойства: `label` (имя кнопки для диктора), `items[{label, icon?, onSelect, danger?, disabled?, checked?}]`, `align` (`left`/`right`), `drop` (`down`/`up`), `className`, `children` (содержимое кнопки).
