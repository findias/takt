# Chip

Метка на карточке, в фильтре и в выборе: плашка-пилюля одного из восьми тонов. Статичная копия классов `.chip` из `styles.css`, класс выбирает `chipClass()` из `entities/label/model.ts`.

- Тон задаёт класс `chip--<тон>` (slate, green, blue, violet, rose, amber, teal, brown), цвета — токены `label-<тон>-bg` и `label-<тон>-fg`.
- `chip--person` — метка-человек: пунктирная обводка без заливки.
- На карточке видно три метки и «+N» (`chip--more`), полный список — в подсказке. Строка меток не должна вырастать в абзац.
- `chip--removable` — в строке фильтра, с крестиком для снятия.

Цвет различает метки, но не объясняет их: название всегда пишется словом.
