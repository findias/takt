# Toast

Всплывающее сообщение о том, что случилось или не получилось. `Takt.Toast` (он же `ToastHost`) и `Takt.useToast` из `web/src/shared/ui/Toast.tsx`.

- Два тона: `info` и `warning`.
- Обратимое действие предлагает вернуть прямо в сообщении («Вернуть») и ничего не спрашивает.
- Общий регион `role="status"`, `aria-live="polite"`; слой `layer-toast`.
- Диалог закрывается до того, как тост докладывает о его действии: верхний слой браузера спрятал бы сообщение.

Вызов: `useToast()({ text, tone, action? })`, где `action = { label, onAct }`; хозяин сообщений — `Toast` вокруг приложения.
