# Hint

Кнопка «?» рядом с термином, открывающая объяснение: `Takt.Hint` из `web/src/shared/ui/Hint.tsx`.

- Термин и текст берутся из каталога подписей (`hint` и `hintText`), ссылка ведёт в раздел справки на языке интерфейса.
- Открывается нажатием, а не наведением: на сенсорном экране наведения нет.
- Текст объявляется диктору через `role="status"`.

Свойства: `topic` — ключ из каталога: `markup`, `limit`, `promise`, `block`, `labelScope`, `visibility`, `iteration`, `cycleTime` и другие.
