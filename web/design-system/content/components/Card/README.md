# Card

Карточка на доске. Статичная копия разметки из `web/src/features/board/CardView.tsx`, в колонке `.column`.

- Сверху — номер, эпик цветной меткой и родитель («↳»): сначала «что это и где я», потом «что делать».
- Название — кнопка, открывает карточку. Исполнители — аватары справа от названия.
- Метки своей строкой: три и «+N».
- Строка пометок: тревога первой (`mark--alarm` — блокировка кирпичным, `mark--aging` — дольше обещанного охрой), затем приоритет (средний не пишется), срок, итерация, оценка.
- У карточки есть меню «…» с «Переместить»: путь в одно нажатие вместо перетаскивания (WCAG 2.5.7).
- Обложек, аватаров-обложек и размеров карточки нет.
