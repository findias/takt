# CopyButton

Кнопка «Скопировать» для ключей, адресов и токенов: `Takt.CopyButton` из `web/src/shared/ui/CopyButton.tsx`.

- Докладывает всплывающим сообщением: «Скопировали ключ.» Поэтому нужен `Toast` вокруг приложения.
- Если буфер обмена недоступен или браузер отказал, говорит об этом и объясняет, что скопировать придётся руками.

Свойства: `value` (что копировать), `what` (что это, для сообщения: «ключ»).
