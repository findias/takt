# Button

Кнопка четырёх видов: главная, обычная, тихая и опасная. Живой компонент `Takt.Button` и `Takt.IconButton` из `web/src/shared/ui/Button.tsx`.

- `btn--primary` — одно главное действие на экран. Отправка формы главная и без класса.
- `btn--default` — всё остальное.
- `btn--quiet` — плотные ряды, действия в тостах и на карточке.
- `btn--danger` — только необратимое. Такая кнопка сначала спрашивает («Удалить доску…»), а у доски ещё и требует набрать её имя.
- `btn--icon` — кнопка без подписи. `aria-label` обязателен, он же уходит в подсказку `title`.

Занятая (`busy` → `aria-busy`) и недоступная кнопки различаются по смыслу: «уже делаю» — не то же, что «сейчас нельзя». Цель нажатия не меньше 24px (`target`). Подпись из одного глагола получает объект в `aria-label`.

Свойства: `kind`, `busy`, `icon`, `disabled`, `ref`; у `IconButton` вместо `icon` — `label`.
