# Иконки

23 иконки из `web/src/shared/ui/icons.tsx`: сетка 24, штрих 2, скруглённые концы и углы, геометрия Lucide. В коде они красятся `currentColor`, размер по умолчанию 16 — кегль текста рядом. Здесь файлы залиты цветом `ink` светлой темы (#16201e), потому что превью через `<img>` не знает `currentColor`.

Иконка всегда декоративная (`aria-hidden`), имя ей даёт кнопка вокруг (`aria-label`). Другие наборы не подмешиваются.
