# Логотип

Знак и слово вместе — для того, что лежит вне продукта: слайды, титулы документов, страница выпуска. В самом интерфейсе рядом со знаком по-прежнему стоит «Takt» системным шрифтом (см. компонент Mark): веб-шрифт в продукте — это брендинг за счёт скорости.

- `takt-logo.svg` — в строку: знак слева, слово справа. Кегль слова — высота знака / 1.4, прописная стоит по центру корпуса, зазор — шестая часть знака.
- `takt-logo-stacked.svg` — столбиком, как в исходном рисунке: слово под знаком, чуть уже его.

Слово — кривые Poppins Medium (лицензия SIL OFL: превращать буквы в кривые для логотипа она разрешает), поэтому файл не зависит от шрифтов у того, кто его открыл. Цвет слова — `#0e4d66`, в тёмной теме `#d3ecf4` (медиазапрос внутри файла). Знак внутри — копия `web/public/takt-mark.svg`, вставленная как есть. Правка знака переносится в логотип заменой всего, что стоит перед `<path class="w"`: кривые слова от знака не зависят, и шрифт для этого не нужен.

Охранное поле — половина высоты знака со всех сторон. Не перекрашивать, не растягивать, не менять шрифт слова.
