# Cheat sheet

What you need on day one. Fits on one A4 sheet.

The interface is in Russian: labels below are quoted the way they
appear on screen, with a translation next to them.

## Where things are

| Where | What is there |
| --- | --- |
| «Доски» (Boards) | boards of the organisation and the archive |
| «Команда» (Team) | people, invitations, labels, keys, subscriptions, export |
| «Структура» (Structure) | subdivisions as a tree |
| Board header | «Доска», «Таблица», «Изменения» — three views of one data set; «Поток» — metrics; «Архив» — archived cards |

## Keys

| Keys | Action |
| --- | --- |
| `Ctrl+K` | find a card or a command |
| Arrows | move between cards |
| `Ctrl` + arrows | move a card between columns |
| `Enter` | open a card |
| `E` | rename without opening |
| `Escape` | close a panel, a menu or the palette |

## Five actions

1. **Create a board** — on the main screen: name, key, «Завести».
2. **Create a card** — at the bottom of a column, then `Enter`.
3. **Move a card** — drag it, or press `Ctrl` with an arrow.
4. **Filter** — the row above the board; the filter lives in the
   address bar, and «Сохранить вид» saves it as a named view.
5. **Archive** — the «…» menu on a card, then «В архив»; «Вернуть»
   appears next to the message.

## When something looks wrong

| You see | It means |
| --- | --- |
| A banner «Связи с сервером нет» | the server is unreachable; nothing you did is lost |
| A card jumped back | the move never reached the server; press «Повторить» |
| The board shows less than you expect | a filter is on; the column says how many are hidden |
