# takt-fetch: выгрузчик для закрытого контура

`takt-fetch` забирает доски из облачного трекера и пишет их
в [пакет переноса](пакет-переноса.md) — один файл `.takt`, который несут
в закрытый контур и там переносят в takt. Пока он знает YouGile; Jira,
Kaiten, Weeek и Trello — следующими.

Отдельная программа намеренно. Её запускают там, где есть интернет, —
обычно на ноутбуке, — а в takt, установленном в закрытом контуре, её
нет: сервер, на котором лежат ваши доски, ни в чьё облако ходить
не умеет, и проверяющий из ИБ видит это по одному списку файлов.

## Где взять

Каждый выпуск несёт `takt-fetch` отдельными файлами, по одному на систему:

| Система | Файл |
| --- | --- |
| Linux, x86-64 / ARM | `takt-fetch-<версия>-linux-amd64`, `…-linux-arm64` |
| macOS, Intel / Apple | `takt-fetch-<версия>-darwin-amd64`, `…-darwin-arm64` |
| Windows, x86-64 / ARM | `takt-fetch-<версия>-windows-amd64.exe`, `…-windows-arm64.exe` |

Сверьте файл с `SHA256SUMS` того же выпуска
(`sha256sum -c SHA256SUMS --ignore-missing`), на Linux и macOS сделайте
его исполняемым (`chmod +x`) и запускайте. Состав поставки —
`takt-fetch.cdx.json` в том же выпуске. Из исходников: `make fetch`
собирает его для этой машины в `bin/takt-fetch`, `make fetch-release` —
под все системы в `dist/`.

`takt-fetch version` печатает версию, `takt-fetch help` — встроенную
справку.

## Войти в YouGile

Учётные данные — из окружения, никогда флагами: флаги видны в списке
процессов и остаются в истории оболочки. В пакет они не пишутся
никогда.

```sh
export YOUGILE_KEY=…                # ключ API компании
# или почта и пароль:
export YOUGILE_LOGIN=anna@company.ru
export YOUGILE_PASSWORD=…           # без него пароль спросят с клавиатуры
```

С почтой и паролем выгрузчик сам получает ключ API компании. Если ключа
у компании ещё нет, он заводит его в YouGile и говорит об этом —
по окончании удалите его там. Если у почты несколько компаний, назовите
одну флагом `--company`. В Windows — `set YOUGILE_KEY=…` в `cmd`
или `$env:YOUGILE_KEY="…"` в PowerShell.

## Найти доску

```sh
takt-fetch yougile boards
```

Печатает по доске на строку: идентификатор, проект и название.
Идентификатор и принимает `--board`.

## Собрать пакет

```sh
takt-fetch yougile fetch --board <id> --out склад.takt --collected-by "Анна, переезд склада"
```

| Флаг | Что делает |
| --- | --- |
| `--board ID` | доска; для нескольких — повторить; `--all` берёт все доски компании |
| `--out ФАЙЛ` | куда записать пакет. Пишется целиком в конце: прерванный запуск не оставит полупакета под этим именем |
| `--no-chats` | без чатов задач: быстрее, но обсуждение не переедет |
| `--no-history` | без истории задач: вдвое меньше запросов, но история «до переноса» у карточек будет пуста |
| `--collected-by ТЕКСТ` | кто собрал и зачем; попадает в пакет как есть и показывается при переносе |
| `--company ИМЯ` | компания, если у почты их несколько |
| `--url АДРЕС` | коробочный YouGile; по умолчанию `https://ru.yougile.com` |

Что попадает в пакет: колонки, задачи с описаниями и чек-листами,
подзадачи (и те, что не стоят ни в одной колонке), исполнители,
стикеры, дедлайны, даты, чаты и история задач. Что не попадает: файлы,
права доступа и учёт времени — пакет их называет, а предпросмотр
переноса показывает под **«Не переносится»**.

**Сколько ждать.** YouGile отвечает не чаще 50 запросов в минуту
на компанию; выгрузчик ждёт всякий раз, когда YouGile об этом просит,
и печатает, сколько сделано. Чат задачи и её история — два запроса,
поэтому доска в 800 задач собирается около получаса; `--no-history`
сокращает это вдвое, вместе с `--no-chats` остаются минуты.

## Перенести и загрузить

Файл пакета читает только его владелец. Пронесите его через периметр
так, как велят ваши правила, а дальше:

- до 50 МБ — экраном: **«Доски»** → **«Перенести задачи из таблицы…»** →
  **«Пакет переноса»**. Тот же предпросмотр, что у таблицы, с выбором
  по каждому человеку;
- больше или много досок подряд — на сервере командой `takt import`
  (см. [установку](установка.md#перенос-досок-в-закрытый-контур)).

Пакет проверяется при чтении целиком: часть, у которой не сошлась
сумма, отвергается и называется.

## Язык

Справка и сообщения следуют `TAKT_LANG`, затем `LC_ALL`, `LC_MESSAGES`,
`LANG` — `ru` или `en`. Если не задано ничего, выгрузчик говорит
по-русски, как и сервер.

## Если отказал

| Сообщение | Что делать |
| --- | --- |
| нужен вход в YouGile: YOUGILE_KEY или YOUGILE_LOGIN | задайте одно из них — см. раздел о входе выше |
| YouGile не принял вход или ключ | проверьте ключ или пароль; ключ принадлежит одной компании |
| у … несколько компаний — назовите одну | добавьте `--company "Название"` |
| не названа ни одна доска | добавьте `--board ID` (из `takt-fetch yougile boards`) или `--all` |
| на доске … N карточек — takt переносит до 10000 | разделите доску в YouGile |
| YouGile не отвечает | проверьте связь с интернетом или `--url` |
| YouGile просит подождать: слишком много запросов | выгрузчик ждёт сам; значит, он выждал свои две минуты — повторите запуск |
| YouGile ответил 500 на … | неполадка на стороне YouGile; повторите позже |

Чат, который YouGile не отдал, доску не останавливает: карточка едет
без него, а пакет говорит, сколько таких чатов было. Ответы «502»,
«503» и «504» выгрузчик пережидает, а не считает поломкой.
