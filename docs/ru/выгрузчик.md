# takt-fetch: выгрузчик для закрытого контура

`takt-fetch` забирает доски из облачного трекера и пишет их
в [пакет переноса](пакет-переноса.md) — один файл `.takt`, который несут
в закрытый контур и там переносят в takt. Пока он знает YouGile, Jira —
облачную и свою установку (Data Center, Server) — и Kaiten, облачный
или коробочный; Weeek и Trello — следующими.

Отдельная программа намеренно. Её запускают там, где есть интернет, —
обычно на ноутбуке, — а в takt, установленном в закрытом контуре, её
нет: сервер, на котором лежат ваши доски, ни в чьё облако ходить
не умеет, и проверяющий из ИБ видит это по одному списку файлов.

## Где взять

Каждый выпуск несёт `takt-fetch` отдельными файлами, по одному на систему:

| Система | Файл |
| --- | --- |
| Linux, x86-64 / ARM | `takt-fetch-<версия>-linux-amd64`, `…-linux-arm64` |
| macOS, Intel / Apple | `takt-fetch-<версия>-darwin-amd64`, `…-darwin-arm64` |
| Windows, x86-64 / ARM | `takt-fetch-<версия>-windows-amd64.exe`, `…-windows-arm64.exe` |

Сверьте файл с `SHA256SUMS` того же выпуска
(`sha256sum -c SHA256SUMS --ignore-missing`), на Linux и macOS сделайте
его исполняемым (`chmod +x`) и запускайте. Состав поставки —
`takt-fetch.cdx.json` в том же выпуске. Из исходников: `make fetch`
собирает его для этой машины в `bin/takt-fetch`, `make fetch-release` —
под все системы в `dist/`.

`takt-fetch version` печатает версию, `takt-fetch help` — встроенную
справку.

## Войти в YouGile

Учётные данные — из окружения, никогда флагами: флаги видны в списке
процессов и остаются в истории оболочки. В пакет они не пишутся
никогда.

```sh
export YOUGILE_KEY=…                # ключ API компании
# или почта и пароль:
export YOUGILE_LOGIN=anna@company.ru
export YOUGILE_PASSWORD=…           # без него пароль спросят с клавиатуры
```

С почтой и паролем выгрузчик сам получает ключ API компании. Если ключа
у компании ещё нет, он заводит его в YouGile и говорит об этом —
по окончании удалите его там. Если у почты несколько компаний, назовите
одну флагом `--company`. В Windows — `set YOUGILE_KEY=…` в `cmd`
или `$env:YOUGILE_KEY="…"` в PowerShell.

## Найти доску

```sh
takt-fetch yougile boards
```

Печатает по доске на строку: идентификатор, проект и название.
Идентификатор и принимает `--board`.

## Собрать пакет

```sh
takt-fetch yougile fetch --board <id> --out склад.takt --collected-by "Анна, переезд склада"
```

| Флаг | Что делает |
| --- | --- |
| `--board ID` | доска; для нескольких — повторить; `--all` берёт все доски компании |
| `--out ФАЙЛ` | куда записать пакет. Пишется целиком в конце: прерванный запуск не оставит полупакета под этим именем |
| `--no-chats` | без чатов задач: быстрее, но обсуждение не переедет |
| `--no-history` | без истории задач: вдвое меньше запросов, но история «до переноса» у карточек будет пуста |
| `--collected-by ТЕКСТ` | кто собрал и зачем; попадает в пакет как есть и показывается при переносе |
| `--company ИМЯ` | компания, если у почты их несколько |
| `--url АДРЕС` | коробочный YouGile; по умолчанию `https://ru.yougile.com` |

Что попадает в пакет: колонки, задачи с описаниями и чек-листами,
подзадачи (и те, что не стоят ни в одной колонке), исполнители,
стикеры, дедлайны, даты, чаты и история задач. Что не попадает: файлы,
права доступа и учёт времени — пакет их называет, а предпросмотр
переноса показывает под **«Не переносится»**.

**Сколько ждать.** YouGile отвечает не чаще 50 запросов в минуту
на компанию; выгрузчик ждёт всякий раз, когда YouGile об этом просит,
и печатает, сколько сделано. Чат задачи и её история — два запроса,
поэтому доска в 800 задач собирается около получаса; `--no-history`
сокращает это вдвое, вместе с `--no-chats` остаются минуты.

## Jira

Тот же пакет — с доски Jira Software. Именно доски, а не проекта:
у доски есть колонки и фильтр, у проекта — ни того ни другого.

**Вход.** Тоже через окружение. Облако (`…atlassian.net`) пускает
по почте и токену API — токен заводится на id.atlassian.com →
**Security** → **API tokens**. Своя установка (Data Center, Server) —
по личному токену из профиля, без почты. Пароля нет вовсе: облако
паролем в API не пускает, а пароль человека в утилите переезда — ровно
то, от чего и уходят токенами.

```sh
export JIRA_EMAIL=anna@company.ru    # только для облака
export JIRA_TOKEN=…
takt-fetch jira boards --url https://company.atlassian.net
takt-fetch jira fetch --url https://company.atlassian.net --board 12 --out dev.takt
```

`boards` печатает id, проект, название и вид доски (`kanban` или
`scrum`). `--board` можно повторять. `--url` обязателен — Jira
по умолчанию нет. `--no-comments` — без комментариев: запросов меньше,
но обсуждение не переедет.

Что переезжает: колонки доски в их порядке, каждая задача — в колонку
своего статуса; название, описание простым текстом (чек-листы —
строками `- [x]`, упоминания — именами), исполнитель, метки, приоритет,
срок, оценка из поля, которым оценивает доска (обычно Story Points),
даты заведения и решения, подзадачи, чей родитель на той же доске,
связи **Blocks** — блокировкой, остальные — просто связью,
и комментарии. Колонка получает подсказку разметки по категории своих
статусов — *К выполнению*, *В работе*, *Готово*, — и в предпросмотре её
можно поменять.

Что нет — и названо в «Не переносится»: вложения, учёт времени,
спринты, версии и история изменений; задачи, чей статус не привязан
ни к одной колонке доски (на доске Jira их тоже не видно), — числом.
В облаке человек может скрыть почту в профиле, и администратор этого
не отменит; такие люди едут по имени, пакет говорит, сколько их,
и сопоставляют их в предпросмотре.

**Своя Jira внутри закрытого контура.** Тогда через периметр не нужно
нести вовсе ничего: запустите `takt-fetch` на машине в том же контуре,
рядом с Jira, с `--url` на её адрес. Если её сертификат выписан
собственным удостоверяющим центром компании, укажите его сертификат
в `SSL_CERT_FILE` — выгрузчик проверку не выключает.

**Сколько ждать.** Задачи приходят по сотне за запрос; комментарии,
не поместившиеся в ответ поиска, — ещё запрос на задачу. Когда Jira
просит подождать (429, 503), выгрузчик ждёт и продолжает.

## Kaiten

Тот же пакет из доски Kaiten — облачного (`компания.kaiten.ru`)
или стоящего у вас: API у них один.

**Вход.** API-ключом из профиля Kaiten, через окружение, как у Jira:

```sh
export KAITEN_TOKEN=…
takt-fetch kaiten boards --url https://company.kaiten.ru
takt-fetch kaiten fetch --url https://company.kaiten.ru --board 345 --out склад.takt
```

`boards` печатает id, пространство и название каждой доски, которую
видно ключу; пространство, куда ключ не пускают, пропускается — как
и в самом Kaiten. `--url` обязателен, `--board` можно повторять,
`--no-comments` — без комментариев: комментарии — запрос на карточку.

Что переезжает: колонки доски по порядку. Колонка с подколонками
становится колонкой на каждую подколонку с именем `Колонка: подколонка`,
чтобы три «В работе» разных колонок не слились в одну; карточка,
лежащая прямо в такой колонке, встаёт в её первую подколонку. Тип
колонки в Kaiten — очередь, в работе, готово — становится подсказкой
разметки. Дальше — название, описание, все участники карточки
исполнителями, теги метками, размер оценкой, флаг ASAP — наивысшим
приоритетом, срок, дата заведения, дата завершения у готовой карточки,
родитель, блокировка другой карточкой доски — связью **«блокирует»**,
комментарии (комментарии в HTML — текстом).

**Дорожки — не колонки.** В Kaiten это ряды поперёк доски, а у takt ряды
строит группировка. Поэтому, когда дорожек на доске больше одной,
карточка получает метку `Дорожка: имя`, и после переноса группировка
**«По метке»** раскладывает доску так же.

**Карточка с несколькими родителями** — Kaiten это позволяет, у takt
дерево — переезжает под первого родителя с доски; пакет говорит,
сколько таких было.

Что не переезжает и названо в **«Не переносится»**: архивные карточки,
причины блокировок, вложения, чек-листы, учёт времени и история
перемещений. Люди, чью почту Kaiten не отдал, приезжают по имени —
сопоставьте их в предпросмотре.

**Kaiten внутри закрытого контура.** Как с Jira: запустите `takt-fetch`
рядом с ним, `--url` — его адрес, и `SSL_CERT_FILE`, если сертификат
подписан своим удостоверяющим центром.

**Сколько ждать.** Карточки приходят по сотне за запрос, плюс запрос
на карточку ради комментариев. Когда Kaiten просит подождать (429),
выгрузчик ждёт до момента, который назвал Kaiten, и продолжает.

## Перенести и загрузить

Файл пакета читает только его владелец. Пронесите его через периметр
так, как велят ваши правила, а дальше:

- до 50 МБ — экраном: **«Доски»** → **«Перенести задачи из таблицы…»** →
  **«Пакет переноса»**. Тот же предпросмотр, что у таблицы, с выбором
  по каждому человеку;
- больше или много досок подряд — на сервере командой `takt import`
  (см. [установку](установка.md#перенос-досок-в-закрытый-контур)).

Пакет проверяется при чтении целиком: часть, у которой не сошлась
сумма, отвергается и называется.

## Язык

Справка и сообщения следуют `TAKT_LANG`, затем `LC_ALL`, `LC_MESSAGES`,
`LANG` — `ru` или `en`. Если не задано ничего, выгрузчик говорит
по-русски, как и сервер.

## Если отказал

| Сообщение | Что делать |
| --- | --- |
| нужен вход в YouGile: YOUGILE_KEY или YOUGILE_LOGIN | задайте одно из них — см. раздел о входе выше |
| YouGile не принял вход или ключ | проверьте ключ или пароль; ключ принадлежит одной компании |
| у … несколько компаний — назовите одну | добавьте `--company "Название"` |
| не названа ни одна доска | добавьте `--board ID` (из `takt-fetch yougile boards`) или `--all` |
| на доске … N карточек — takt переносит до 10000 | разделите доску в YouGile |
| YouGile не отвечает | проверьте связь с интернетом или `--url` |
| YouGile просит подождать: слишком много запросов | выгрузчик ждёт сам; значит, он выждал свои две минуты — повторите запуск |
| YouGile ответил 500 на … | неполадка на стороне YouGile; повторите позже |
| не назван адрес Jira | добавьте `--url https://company.atlassian.net` или адрес своей установки |
| нужен вход в Jira: JIRA_EMAIL и JIRA_TOKEN | для облака задайте оба, для своей установки — один `JIRA_TOKEN` |
| Jira не приняла вход | проверьте почту и токен; облачный токен действует только со своей почтой |
| Jira не пускает к этой доске | у учётной записи нет права просматривать проект доски |
| адрес отвечает, но это не Jira | `--url` ведёт не туда — на страницу входа или прокси |
| на доске … больше 10000 задач | сузьте фильтр доски в Jira или соберите доску частями |
| не назван адрес Kaiten | добавьте `--url https://company.kaiten.ru` или адрес своего сервера |
| нужен вход в Kaiten: KAITEN_TOKEN | задайте API-ключ из профиля Kaiten |
| Kaiten не принял токен | ключ отозван или он от другого Kaiten |
| Kaiten не пускает к этой доске | у учётной записи нет доступа к пространству доски |
| адрес отвечает, но это не Kaiten | `--url` ведёт не туда — на страницу входа или прокси |
| на доске … больше 10000 карточек | разделите доску в Kaiten |

Чат, который YouGile не отдал, доску не останавливает: карточка едет
без него, а пакет говорит, сколько таких чатов было. Ответы «502»,
«503» и «504» выгрузчик пережидает, а не считает поломкой.
