# Пакет переноса

**Версия формата 1.** takt его читает — на экране переноса и командой
`takt import` на сервере. Пишет его [`takt-fetch`](выгрузчик.md) из того же выпуска;
пока — из YouGile, остальные трекеры из списка ниже придут следом.

## Зачем он

Пакет переноса — один файл, в котором доски из другого трекера —
YouGile, Jira, Trello, Kaiten, Weeek, Asana, Notion, ClickUp, monday —
переезжают в takt, установленный в закрытом контуре.

Переезд разрезан надвое по периметру. Снаружи, где есть интернет,
`takt-fetch` входит в чужой трекер, собирает доски и пишет пакет.
Файл переносят через периметр тем способом, который сеть позволяет.
Внутри takt читает пакет и переносит его через тот же предпросмотр,
что и таблицу: куда ложится каждая колонка, чьи почты не нашлись,
что не переехало. Сервер takt в закрытом контуре не открывает ради
этого ни одного нового соединения, и кода, говорящего с облаками
чужих трекеров, у него не прибавляется.

Почему пакет, а не таблица: таблица теряет то, чему нет ячейки, —
подзадачи, связи между карточками, обсуждение, несколько досок разом.
Пакет их сохраняет.

## Файл

Архив ZIP с расширением `.takt`. Внутри:

| Часть | Что |
| --- | --- |
| `manifest.json` | что это за пакет, откуда он, SHA-256 каждой другой части |
| `boards/<n>.json` | одна доска: колонки, люди, метки, карточки; `<n>` — 1, 2, 3… |

Ничего другого не читается; любая другая часть отвергается, а не
пропускается, — чтобы пакет не пронёс мимо читающего ничего незаметно.
Текст — JSON в UTF-8. Моменты — RFC 3339 в UTC (`2026-09-22T10:15:00Z`),
даты без времени — `YYYY-MM-DD`.

## manifest.json

```json
{
  "format": "takt-import-package",
  "version": 1,
  "createdAt": "2026-09-22T10:15:00Z",
  "createdBy": "takt-fetch v0.4.0",
  "collectedBy": "Anna Clarke, migration of the warehouse boards",
  "source": {
    "system": "yougile",
    "url": "https://ru.yougile.com",
    "account": "Northern logistics"
  },
  "boards": [
    { "file": "boards/1.json", "sha256": "9f2c…", "title": "Warehouse", "cards": 214 }
  ],
  "lost": ["task chats: files attached to messages"]
}
```

| Поле | Смысл |
| --- | --- |
| `format` | всегда `takt-import-package`: отличает пакет от любого другого JSON |
| `version` | версия формата, целое число. Незнакомую версию читающий отвергает и говорит, какие версии он читает |
| `createdAt`, `createdBy` | когда и какой программой записан пакет |
| `collectedBy` | свободный текст: кто собрал и зачем. Не подпись — в версии 1 пакет не подписывается |
| `source.system` | откуда доски: `yougile`, `jira`, `trello`, `kaiten`, `weeek`, `asana`, `notion`, `clickup`, `monday` |
| `source.url`, `source.account` | какая установка и какая учётная запись или компания — для отчёта |
| `boards` | каждая часть с доской: её SHA-256 (шестнадцатеричный, строчными), название и число карточек |
| `lost` | что источник знал, а пакет не несёт, — словами; показывается в предпросмотре под **«Не переносится»** |

**Целостность.** Читающий считает SHA-256 каждой части с доской
и сверяет с манифестом; одно расхождение — и отвергается весь пакет
с названием части. Это ловит файл, испорченный по дороге. Кто написал
пакет, это не доказывает: в версии 1 подписи у пакета нет.

## boards/&lt;n&gt;.json

```json
{
  "externalId": "b-1",
  "title": "Warehouse",
  "columns": [
    { "externalId": "c-1", "title": "To do", "kind": "queue" },
    { "externalId": "c-2", "title": "In progress", "kind": "in_progress" },
    { "externalId": "c-3", "title": "Done", "kind": "done" }
  ],
  "people": [
    { "externalId": "u-1", "email": "anna@example.test", "name": "Anna Clarke" },
    { "externalId": "u-2", "email": null, "name": "Ivan Petrov" }
  ],
  "labels": [
    { "externalId": "st-2", "name": "Area: Warehouse 2" }
  ],
  "cards": [
    {
      "externalId": "t-1",
      "title": "Reconcile stock",
      "description": "Warehouse 2, by Friday",
      "column": "c-1",
      "assignees": ["u-1", "u-2"],
      "labels": ["st-2"],
      "estimate": 3,
      "priority": "high",
      "due": "2026-09-30",
      "createdAt": "2026-09-02T08:00:00Z",
      "finishedAt": null,
      "parent": null,
      "links": [{ "kind": "blocks", "to": "t-4" }],
      "comments": [
        { "author": "u-2", "at": "2026-09-03T09:12:00Z", "text": "Started with row 1" }
      ]
    }
  ],
  "lost": []
}
```

Всякий объект называется своим `externalId` — идентификатором
в системе-источнике, строкой. Ссылки ведут только внутрь того же файла
доски; `parent` или цель связи на другой доске отбрасывается
и называется в отчёте.

**Колонки** перечислены в порядке доски. `kind` — подсказка: `queue`,
`in_progress`, `done` или `null`, если выгрузчик не понял; предпросмотр
её показывает, и на существующей доске человек может отдать любую
колонку в другую — так же, как у таблицы.

Доска с `"historyCollected": true` говорит, что выгрузчик собирал
историю задач: у карточки без `history` её просто не было, и потом
ничего не дотягивается.

**Люди** сопоставляются с организацией по почте, без учёта регистра;
в предпросмотре владелец может сопоставить любого с участником,
завести учётную запись или не переносить, и без этого выбора никто
не заводится. `email` — `null`, когда источник его
не отдал: Trello отдаёт почты участников только администратору рабочего
пространства, поэтому в пакете, собранном кем-то другим, почт нет,
и `takt-fetch` говорит об этом до начала. Человек без пары
не назначается; отчёт называет его почтой или именем, а его карточки
получают техническую метку с его именем — по одной на человека,
различаемого по `externalId`, так что у двух тёзок две метки.

**Метки** становятся метками доски по названию; одноимённая метка,
уже действующая на доске, берётся она.

**Карточки**:

| Поле | Обязательно | Смысл |
| --- | --- | --- |
| `externalId` | да | идентификатор задачи в источнике; вместе с `source.system` это ключ, по которому повторный перенос пропускает уже переехавшее |
| `number` | нет | номер задачи, каким его знают люди (`DEV-12`); его называет история карточки, чтобы задачу можно было найти в старой системе. Без него история называет `externalId`, если это не UUID |
| `title` | да | непустой; карточка без названия не переносится и называется |
| `description` | нет | простой текст; выгрузчик переводит разметку источника в текст и дописывает чек-листы строками `- [x] пункт` |
| `column` | да | `externalId` колонки этой доски |
| `assignees`, `labels` | нет | `externalId` людей и меток этой доски |
| `estimate` | нет | положительное число |
| `priority` | нет | `low`, `medium`, `high`, `highest`; нет поля — `medium` |
| `due` | нет | дата |
| `createdAt`, `finishedAt` | нет | моменты; `finishedAt` у карточки в готовой колонке — когда её закончили |
| `parent` | нет | `externalId` родительской карточки: карточка становится её частью (подзадачей) |
| `links` | нет | `blocks` или `relates`, к `externalId` карточки этой доски |
| `comments` | нет | по порядку времени; `author` — `externalId` человека или `null` |
| `history` | нет | история задачи в источнике — кто что сделал и когда — по порядку времени, того же вида, что `comments`. Карточка показывает её «до переноса», отдельно от своей истории здесь |

Ключ повторного переноса — `source.system` вместе с `externalId`
карточки. У YouGile это тот же ключ, что у переноса по API, поэтому
доска, привезённая сначала по API, а потом пакетом, дважды не приедет.

**Комментарии** переезжают со своей датой. Автор — найденный по почте
человек; иначе комментарий пишется от имени того, кто переносит,
и начинается с имени автора текстом — «из YouGile: Иван Петров», —
чтобы никто не был выдуман и ничего не приписано не тому.

**История** подчиняется правилу всякого переноса: даты переезжают,
переходы между колонками — нет. У прежней системы свои колонки, и её
переходы, выданные за наши, дали бы метрику, которой никто не может
верить. Перенесённые карточки помечены, и **«Поток»** умеет считать
без них.

## Пределы

| Что | Предел | Сверх него |
| --- | --- | --- |
| карточек на одной доске | 10 000 | доска отвергается с числом; разделите её в источнике |
| пакет, загруженный на экране переноса | 50 МБ | экран так и говорит; администратор переносит его с командной строки на сервере, где размер файла не ограничен |
| одна часть в распакованном виде | 256 МБ | пакет отвергается: маленький архив, распаковывающийся в гигабайты, — не пакет |
| частей | 1 000 | пакет отвергается |

## Чего в пакете не бывает никогда

Паролей, ключей API, токенов и cookie сессий системы-источника.
`takt-fetch` берёт их из командной строки или окружения и никуда
не пишет; проверка ищет в каждом записанном пакете ключ, который
выгрузчику дали.

## Версии

Изменение, которое существующий читающий понял бы неверно, —
переименованное поле, сменившийся смысл, новое обязательное поле, —
поднимает `version`. Новое необязательное поле — не поднимает:
незнакомые поля внутри `boards/<n>.json` читающий пропускает.
Читающий называет все версии, которые принимает, а более новый пакет
отвергается с перечнем версий, которые читает эта установка, — чтобы
ответом было «обновите takt», а не наполовину перенесённая доска.
