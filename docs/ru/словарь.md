# Словарь

Одно понятие — одно слово. Это слова, которыми говорят интерфейс и эта
документация, и что каждое из них значит в Takt.

## Работа на доске

| Слово | Что значит |
| --- | --- |
| Доска | Работа одной команды, которая движется по колонкам. У доски есть ключ, видимость и, если команда его задала, обещание |
| Ключ доски | Короткое начало номеров карточек: `ПОСТ` даёт `ПОСТ-14`. Задаётся один раз, при заведении доски: номера карточек уходят в переписку и меняться не должны |
| Карточка | Одна единица работы. Её номер — ключ доски и порядковое число |
| Колонка | Этап, через который проходит работа: у новой доски **«Очередь»**, **«В работе»**, **«Готово»** |
| Разметка колонок | Две отметки на колонках: **начало работы** — с этой колонки работа считается начатой; **финиш** — здесь она считается законченной. Метрики потока считаются по разметке, а не по датам, заполненным руками |
| Лимит колонки | Сколько карточек колонке стоит держать. Превышение подсвечивается, но не запрещается: лимит нужен, чтобы перегруз был виден |
| Жёсткий лимит | Лимит, который отказывает: в полную колонку карточку не перенести, и отказ говорит сначала освободить место |
| Обещание доски | За сколько дней работа обычно проходит доску и с какой вероятностью — «обычно 8 дней с вероятностью 85%». Карточки, идущие дольше, собирает отбор **«Дольше обещанного»** |
| Блокировка | Карточка, которая чего-то ждёт, всегда с причиной. У блокировки может быть срок, после которого она снимется сама |
| Подзадача | Часть карточки. Это обычная карточка, она может жить на доске другой команды; у задачи видно «сколько из скольких» |
| Метка | Отметка на карточке. Принадлежит одному из трёх мест — организации, подразделению (со всем, что в него вложено) или одной доске — и предлагается только там |
| Итерация | Спринт или релиз: название и даты. Закрытие навсегда замораживает её состав и даёт отчёт |
| Дорожки | Доска, разрезанная на ряды по исполнителю, метке, итерации или приоритету. Срез той же доски, а не другая доска |
| Отбор | Условия, которые прячут остальную доску. Живёт в адресе страницы, поэтому им можно поделиться ссылкой |
| Сохранённый вид | Отбор, группировка и раскладка под именем, чтобы к ним вернуться |
| Архив | Куда уходят убранные карточки и доски. Всё оттуда можно вернуть; удаление насовсем — отдельное действие, которое называет, что исчезнет |

## Метрики потока

| Слово | Что значит |
| --- | --- |
| Время цикла | Сколько дней работа идёт от **начала работы** до **финиша**; показывается перцентилями, а не средним |
| Пропускная способность | Сколько карточек доходит до **финиша** за неделю |
| В работе | Сколько карточек сейчас между **началом работы** и **финишем** |
| Возраст | Сколько уже идёт карточка, которая ещё в работе |
| Накопление | Три полосы по дням — не начато, в работе, сделано, — чтобы видеть, где работа копится |
| Прогноз | Сколько дней может занять довести столько-то карточек, тремя перцентилями: «если дальше пойдёт как шло» |
| Выброшено | Карточки, убранные с доски незавершёнными |

## Организация

| Слово | Что значит |
| --- | --- |
| Организация | Все, кто работает в одном Takt, и их доски. Организации друг друга не видят |
| Подразделение | Отдел или команда в дереве организации. Ему могут принадлежать доски и метки |
| Владелец | Читает, меняет работу и управляет организацией |
| Участник | Читает и меняет работу |
| Наблюдатель | Только читает |
| Администратор подразделения | Управляет своим поддеревом: кто в нём, вложенные подразделения, доски |
| Наблюдатель области | Читает всё в своём поддереве |
| Видимость доски | Кто видит доску: вся организация, своё подразделение или только вписанные |
| Ключ интеграции | Доступ для другой системы, ограниченный выданными разрешениями; отзывается одним действием |
| Подписка на события | Адрес, который получает событие каждый раз, когда с карточками что-то происходит |
