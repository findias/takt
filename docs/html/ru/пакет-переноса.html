Пакет переноса

Версия формата 1. takt его читает — на экране переноса и командой takt import на сервере. Пишет его takt-fetch из того же выпуска; пока — из YouGile, остальные трекеры из списка ниже придут следом.

Зачем он

Пакет переноса — один файл, в котором доски из другого трекера — YouGile, Jira, Trello, Kaiten, Weeek, Asana, Notion, ClickUp, monday — переезжают в takt, установленный в закрытом контуре.

Переезд разрезан надвое по периметру. Снаружи, где есть интернет, takt-fetch входит в чужой трекер, собирает доски и пишет пакет. Файл переносят через периметр тем способом, который сеть позволяет. Внутри takt читает пакет и переносит его через тот же предпросмотр, что и таблицу: куда ложится каждая колонка, чьи почты не нашлись, что не переехало. Сервер takt в закрытом контуре не открывает ради этого ни одного нового соединения, и кода, говорящего с облаками чужих трекеров, у него не прибавляется.

Почему пакет, а не таблица: таблица теряет то, чему нет ячейки, — подзадачи, связи между карточками, обсуждение, несколько досок разом. Пакет их сохраняет.

Файл

Архив ZIP с расширением .takt. Внутри:

ЧастьЧто
manifest.jsonчто это за пакет, откуда он, SHA-256 каждой другой части
boards/<n>.jsonодна доска: колонки, люди, метки, карточки; <n> — 1, 2, 3…

Ничего другого не читается; любая другая часть отвергается, а не пропускается, — чтобы пакет не пронёс мимо читающего ничего незаметно. Текст — JSON в UTF-8. Моменты — RFC 3339 в UTC (2026-09-22T10:15:00Z), даты без времени — YYYY-MM-DD.

  "source": {
    "system": "yougile",
    "url": "https://ru.yougile.com",
    "account": "Northern logistics"

  "boards": [
    { "file": "boards/1.json", "sha256": "9f2c…", "title": "Warehouse", "cards": 214 }
  ],
  "lost": ["task chats: files attached to messages"]
}
ПолеСмысл
formatвсегда takt-import-package: отличает пакет от любого другого JSON
versionверсия формата, целое число. Незнакомую версию читающий отвергает и говорит, какие версии он читает
createdAt, createdByкогда и какой программой записан пакет
collectedByсвободный текст: кто собрал и зачем. Не подпись — в версии 1 пакет не подписывается
source.systemоткуда доски: yougile, jira, trello, kaiten, weeek, asana, notion, clickup, monday
source.url, source.accountкакая установка и какая учётная запись или компания — для отчёта
boardsкаждая часть с доской: её SHA-256 (шестнадцатеричный, строчными), название и число карточек
lostчто источник знал, а пакет не несёт, — словами; показывается в предпросмотре под «Не переносится»

Целостность. Читающий считает SHA-256 каждой части с доской и сверяет с манифестом; одно расхождение — и отвергается весь пакет с названием части. Это ловит файл, испорченный по дороге. Кто написал пакет, это не доказывает: в версии 1 подписи у пакета нет.

Всякий объект называется своим externalId — идентификатором в системе-источнике, строкой. Ссылки ведут внутрь того же файла доски, с одним исключением: parent карточки может лежать на другой доске того же пакета — эпик на доске-портфеле, его фича на доске команды. Доски переносятся по одной и в любом порядке; какая из двух переедет второй, та и делает карточку частью родителя, а до того отчёт называет доску, которую осталось перенести. Цель связи на другой доске и parent, которого нет ни на одной доске пакета, отбрасываются и называются в отчёте.

Колонки перечислены в порядке доски. kind — подсказка: queue, in_progress, done или null, если выгрузчик не понял; предпросмотр её показывает, и на существующей доске человек может отдать любую колонку в другую — так же, как у таблицы.

Доска с "historyCollected": true говорит, что выгрузчик собирал историю задач: у карточки без history её просто не было, и потом ничего не дотягивается.

Доска с "level": "portfolio" — портфель эпиков: перенесённая в новую доску, она становится доской-портфелем без итераций, а её карточки — эпиками. Без level или с "team" — доска команды. Прежняя версия takt поле не читает и заводит обычную доску.

Люди сопоставляются с организацией по почте, без учёта регистра; в предпросмотре владелец может сопоставить любого с участником, завести учётную запись или не переносить, и без этого выбора никто не заводится. email — null, когда источник его не отдал: Trello отдаёт почты участников только администратору рабочего пространства, поэтому в пакете, собранном кем-то другим, почт нет, и takt-fetch говорит об этом до начала. Человек без пары не назначается; отчёт называет его почтой или именем, а его карточки получают техническую метку с его именем — по одной на человека, различаемого по externalId, так что у двух тёзок две метки.

Метки становятся метками доски по названию; одноимённая метка, уже действующая на доске, берётся она.

Ключ повторного переноса — source.system вместе с externalId карточки. У YouGile это тот же ключ, что у переноса по API, поэтому доска, привезённая сначала по API, а потом пакетом, дважды не приедет.

Комментарии переезжают со своей датой. Автор — найденный по почте человек; иначе комментарий пишется от имени того, кто переносит, и начинается с имени автора текстом — «из YouGile: Иван Петров» или «автор неизвестен», если источник его не назвал, — чтобы никто не был выдуман и ничего не приписано не тому.

История подчиняется правилу всякого переноса: даты переезжают, переходы между колонками — нет. У прежней системы свои колонки, и её переходы, выданные за наши, дали бы метрику, которой никто не может верить. Перенесённые карточки помечены, и «Поток» умеет считать без них.

Чего в пакете не бывает никогда

Паролей, ключей API, токенов и cookie сессий системы-источника. takt-fetch берёт их из командной строки или окружения и никуда не пишет; проверка ищет в каждом записанном пакете ключ, который выгрузчику дали.

Версии

Изменение, которое существующий читающий понял бы неверно, — переименованное поле, сменившийся смысл, новое обязательное поле, — поднимает version. Новое необязательное поле — не поднимает: незнакомые поля внутри boards/<n>.json читающий пропускает. Читающий называет все версии, которые принимает, а более новый пакет отвергается с перечнем версий, которые читает эта установка, — чтобы ответом было «обновите takt», а не наполовину перенесённая доска.
