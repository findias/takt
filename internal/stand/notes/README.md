# Заметка тестового стенда

Сюда при сборке образа стенда кладутся `branch.txt` (имя ветки)
и `log.txt` (коммиты ветки поверх master) — их пишет workflow «Стенд»
(`.github/workflows/stand.yml`). Оба файла в `.gitignore`: в репозитории
их нет, и сборка выпуска получает пустую заметку — байт в байт ту же,
что проверяет воспроизводимость.

Сам этот файл нужен, чтобы каталог существовал: `go:embed` без единого
файла не собирается.
